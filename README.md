# 🧠 Quiz App

An interactive Quiz Application built with React that provides users with an engaging way to test their knowledge through multiple-choice questions. The application features a clean user interface, responsive design, and real-time score tracking.

## 🚀 Live Demo

🔗 https://quiz-app-beta-eosin-39.vercel.app/

---

## 📖 About

This project was developed to practice React concepts such as component-based architecture, state management, conditional rendering, and event handling. The application presents quiz questions, evaluates user responses, and displays the final score upon completion.

---

## ✨ Features

- Interactive multiple-choice quiz
- Responsive design for desktop and mobile devices
- Real-time score calculation
- Question navigation
- Final results screen
- Clean and intuitive user interface
- Fast performance with React

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/k021104/Quiz-app.git
```

Navigate to the project

```bash
cd Quiz-app
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open your browser and visit

```
http://localhost:5173
```

---

## 📦 Build for Production

```bash
npm run build
```

Preview the production build

```bash
npm run preview
```

---

## 🎯 How It Works

1. Start the quiz.
2. Read each question carefully.
3. Select the correct answer.
4. Continue until all questions are completed.
5. View your final score.
